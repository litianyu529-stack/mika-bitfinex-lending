# Bitfinex-lendingbot V3.5 发布说明

V3.5 将最近两轮安全恢复和定价调价升级合并为一个正式版本。该修正版应用与 HTTP User-Agent 版本为 `0.3.5.2`，Dashboard 显示 `V3.5`。内部 `RuntimeV3`、`StrategyV3`、状态库文件名及策略协议标识继续保持兼容。

## 0.3.5.2 快速层定价与调价

- 新建快速层订单采用与平衡层相同的同期限锚点、1 小时中位数、24 小时 Q75 和 5% 起始保护，不再默认直接挂在硬底线。
- 快速层使用独立的短/中/长期十阶段时间表，默认分别在 30/60/180 分钟到达固定市场落点，并最迟在 90/180/720 分钟到达硬底线。
- 新订单使用 `EXACT_TERM_EXPLORATION_V4`。既有 V2/V3/Legacy 订单继续原定价曲线和时间表，升级不会使旧挂单集中追赶调价。
- 快速层时间表可在 Dashboard 中独立编辑；本次升级继续使用原 V3.5 数据分界，不新增数据库 Schema。

## 无人值守安全与恢复

- 网络、认证、配置、行情、账户快照和 Worker 异常统一进入无写入的 PAUSED 恢复流程；除人工暂停或停止外，满足连续权威快照条件后自动恢复原运行模式。
- 未知提交、未知撤单、小额订单合并及外部挂单接管统一暴露为持久化写入阻断，未完成权威对账前禁止产生新的交易写入。
- 重启后继续处理既有恢复状态，清理已经被权威快照证明失效的观察记录，避免旧状态永久阻塞 LIVE。
- 外部 fUSD 挂单仍需两次权威快照确认后才会被托管，并且只按具体 Offer ID 操作；外部 Credits 不接管、不提前关闭。

## 精确期限定价与单向调价

- 全部成交先经过异常值过滤，再分别计算各精确期限的市场数据。0.3.5.2 新建快速层与平衡层结合同期限锚点、1 小时中位数、24 小时 Q75 和相对底线的 5% 起始保护；高收益层结合24小时/7天 Q75、IQR 和相对底线的 12% 起始保护。旧快速层链继续使用其原始竞争价曲线。
- 新订单将创建时的同期限市场落点持久化。快速层和平衡层在第 5 阶段到达固定落点，高收益层在第 7 阶段到达固定落点；市场后续变化只影响新订单。
- 新建订单链采用 10 个期限专属阶段，利率只能持平或下降。普通层短期／中期／长期底线阶段分别在累计等待 180／360／1440 分钟到期；0.3.5.2 新快速层对应 90／180／720 分钟。时间表表示阶段到期资格，实际执行仍受账户确认、运行周期及写入限制影响。
- 停止执行 `MARKET_RISE` 和 `QUICK_PERIOD_CORRECTION` 旁路。最终底线阶段优先于普通同层冷却和每小时调价限制，但仍遵守交易所写入速率、确认、余额对账和未知写入保护。
- 类型纠正、撤单重挂和策略同步继承原金额、期限、层级、起始时间、阶段及固定落点，重挂利率不得高于当前订单。
- 部分成交后的剩余金额不足 150 USD 时不撤单，Dashboard 明确显示“低于交易所重挂最低金额”。

## 数据与升级

状态数据库升级为 Schema 16，新增订单意图及调价链的固定市场落点。迁移前仍执行在线备份，迁移过程保持事务性；现有策略、历史审计、分支、标签和用户配置不被删除。旧订单链若意外存在，会在首次权威同步时固定一次同期限落点，且不会高于原始起价。

对于已经运行精确期限探索机制的状态库，V3.5 从首笔 `EXACT_TERM_EXPLORATION_V2/V3/V4` 订单向前关联最近的 LIVE 启动事件，并将该事件作为数据分界。没有历史新机制数据的新安装使用首次 V3.5 启动时间。状态接口围绕分界提供更新前后等长窗口的订单与成交统计，包括精确期限、金额、加权日利率和加权等待时间；后续重启不会移动分界。

本次发布不改变资金池比例、层级比例、APR 底线或已经配置的各期限最终调价时间，也不增加成交救援机制。
