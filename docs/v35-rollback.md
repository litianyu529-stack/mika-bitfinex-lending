# 迁回 USD V3 运行时

`RollbackV35.py` 将旧 V4 USD 运行记录投影到 Schema 16 备份副本，再将新副本迁移到当前 V3 的 Schema 19。开始前停止控制台和 Worker，保留源数据库、升级前备份和配置。

```powershell
python RollbackV35.py --source <V4-USD-数据库> --legacy-backup <Schema-16-备份> --output <新数据库>
```

源文件与备份均以只读方式打开。目标必须是新路径。工具拒绝跨币记录、未知交易写入、受保护暂停及未对账的调价。归属、订单等待时间、贷款、账本与行情按兼容字段保留。

恢复后的策略沿用源库中最近启用过的 V3.5 策略，包括固定金额和资金比例上限。核对输出的策略参数与目标数据库后，从 PAUSED 通过正常只读预检和人工确认启动 USD。
