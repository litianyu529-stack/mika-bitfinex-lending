# 手动订单两小时保护

手动新挂的 USD Funding 订单和手动修改过的机器人订单，从交易所最近可识别的操作时间起保护 120 分钟。再次修改报价、期限、原始金额、类型或标志会重新计时；正常部分成交、浮动利率变化和单纯更新时间变化不重置计时。手动撤单后重新挂出的新 ID 单独计时，机器人自己重挂的订单通过持久化提交意图区分。

保护期内普通调价、自动接管和小额余额合并跳过该单，其他订单照常运行。满两小时仍存在的剩余挂单，在权威账户快照一致、两次快照至少间隔 30 秒确认且允许写入后，按具体 Offer ID 撤单，再使用现有策略重新规划。满两小时表示具备接管资格，不保证该时刻立即成交或撤单。

用户选择允许强制安全规则提前处理：利率底线、禁止期限／类型、隐藏订单限制和资金上限仍然生效。外部单提前处理仍需两次权威快照确认，日志保留具体理由。结果未知的交易所写入继续使用原有暂停和对账流程。

交易所最新更新时间可能包含部分成交，首次发现且无法区分时使用该时间保守延后。缺失或异常时间使用首次发现时间，并在控制台说明。没有参数变化、也没有可区分事件的相同参数重复操作无法识别。撤单前重新读取实时挂单；读取失败或参数变化时跳过本轮撤单。已发往交易所的撤单无法因随后发生的人工操作撤回。

Schema 19 新增独立保护记录，升级前在线备份 Schema 18（也支持 Schema 16 升级），不撤销原有订单及成交归属。保护记录跨重启保留；原手动改单前的调价任务失效。启动预检只预览接管候选，不直接接管；实际接管统一由 Worker 执行。该功能包含在 `0.3.6.1-rc.1` 预览版中，仍使用现有 API 路径，`openOffers[].manualProtection` 新增状态、操作时间、截止时间、剩余秒数、时间来源和处理理由。

本次不改变资金比例、利率公式或 V3.6 候选启用证书要求。生产迁移必须在 Worker 和旧 Dashboard 停止后进行，再通过正常预检启动新 Worker。
